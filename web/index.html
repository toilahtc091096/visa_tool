Lấy token trang bio
Dùng khi /run báo lỗi token. Bấm mở trang đăng nhập: tab mới tự điền tài khoản của nhà, bạn làm bước xác minh rồi đăng nhập, token tự gửi về (tab đăng nhập vẫn giữ nguyên). Mọi curl sau đó của nhà này dùng token mới.
Máy này chưa cài script lấy token (làm 1 lần): 1. Cài tiện ích Tampermonkey: Chrome Web Store (Edge: tìm "Tampermonkey" trong cửa hàng tiện ích của Edge). 2. Chrome/Edge mới: vào trang quản lý tiện ích → Tampermonkey → Chi tiết → bật "Cho phép tập lệnh của người dùng" (Allow User Scripts). 3. Bấm Cài script → trong Tampermonkey bấm "Cài đặt". 4. Tải lại trang này (F5).
Cách thủ công (khi tab bio không tự gửi token)
Đăng nhập trang bio xong, chép địa chỉ trang (có token=…), hoặc chính token, hoặc một curl có dòng Authorization, dán vào đây rồi bấm Lưu. Server kiểm tra token trước khi lưu.
