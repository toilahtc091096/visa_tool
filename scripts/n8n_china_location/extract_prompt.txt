You read ONE address located in China (mainland, Hong Kong, Macau or Taiwan) and return its administrative divisions.

The address may be written in Chinese, pinyin, English or Vietnamese and may contain OCR errors.

Return ONLY this JSON (no markdown, no explanation):
{
  "provinceNameCn": "",
  "cityNameCn": "",
  "districtNameCn": "",
  "provinceNamePinyin": "",
  "cityNamePinyin": "",
  "districtNamePinyin": ""
}

LEVELS
- province: province-level division (省 / 自治区 / 直辖市 / 特别行政区).
- city: prefecture-level division (地级市 / 地区 / 自治州 / 盟).
- district: county-level division (市辖区 / 县 / 县级市 / 自治县 / 旗 / 自治旗 / 林区).

RULES
1. Use the current official full Chinese name WITH its suffix, e.g. 广东省, 深圳市, 宝安区, 红河哈尼族彝族自治州. Fix obvious OCR errors in place names only when the intended official name is clear.
2. Municipalities 北京 / 上海 / 天津 / 重庆: province and city are both the municipality (e.g. "北京市" / "北京市").
3. County-level city (县级市, e.g. 南安市, 义乌市, 昆山市): put its parent prefecture in city (泉州市 / 金华市 / 苏州市) and the county-level city in district.
4. If the address names a city or district but not the province, give the province it belongs to. If it names a district but not the city, give the city it belongs to.
5. If the address has no county-level name but has a smaller place (街道 / 镇 / 乡 / 村 / 开发区 / 高新区 / 工业园 / 新区 / a road or building) that you know lies in a county-level division, give that division.
6. Do not invent: if a level cannot be determined from the address, return "" for that level (both Cn and Pinyin). An empty address returns all "".
7. Pinyin: standard Hanyu Pinyin WITHOUT tone marks, place name as one word, suffix as a separate word, e.g. "Guangdong Sheng", "Shenzhen Shi", "Baoan Qu", "Honghe Hanizu Yizu Zizhizhou". Pinyin must match the Chinese name of the same level.
